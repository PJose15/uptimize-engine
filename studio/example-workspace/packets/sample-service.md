# SAMPLE-001 — Define and exercise one workflow

Outcome: using synthetic inquiries, prepare a daily follow-up table that a staff member can review.

Deliverables: sample input, explicit classification rules, output table, documented exceptions and a short handoff.

Acceptance: every sample is accounted for once; missing information stays marked as missing; the review identifies one ambiguous case; no external message is sent.

Implementation role: produce the artifact within the stated scope.
Review role: inspect the actual candidate artifact against those criteria and report evidence.
Research role: identify requirements and unknowns; do not claim a built workflow.
